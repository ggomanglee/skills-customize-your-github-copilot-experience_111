# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build the classic word-guessing game using Python strings, loops, and user input to practice core programming concepts.

## 📝 Tasks

### 🛠️ Create the game loop

#### Description
Design a simple Hangman game where the player guesses letters to reveal a hidden word before running out of attempts.

#### Requirements
Completed program should:

- Randomly select words from a predefined list
- Accept single-letter guesses from the user
- Show the current progress using underscores and correctly guessed letters
- Track how many incorrect guesses remain

### 🛠️ Handle game state

#### Description
Implement the logic that tracks the player's progress and determines when the game ends.

#### Requirements
Completed program should:

- Update the guessed-letter state after each turn
- Prevent duplicate guesses from counting multiple times
- End the round when the word is fully guessed or attempts are exhausted
- Display clear win/lose messages

### 🛠️ Add polish

#### Description
Improve the game experience so it feels complete and easy to play.

#### Requirements
Completed program should:

- Show the letters already guessed
- Include a friendly start or restart flow
- Use consistent formatting and clear prompts for the player
